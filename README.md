# Learning Robot Metareasoning: Adaptive Computation Budgets for Real-Time Control

Anonymous supplementary website for ICRA 2027. Static HTML, CSS and JavaScript; no build step or external fonts, analytics, or runtime libraries.

Preview with `python3 -m http.server 8765`, then open `http://localhost:8765`.
Run the interaction and asset checks with `node test-site.cjs`.

The method animation reuses the paper/presentation diagram layers. Planner-statistic animations and the budget slider are schematic explanations, not experimental traces. Navigation headline values follow the pooled results CSV; the input ablation is a separate evaluation. The RoboMaster image is rendered from the supplied STEP reconstruction. CAD geometry is used for illustration, not as evidence of matched dynamics. The ROS timing description follows the deployment implementation and makes no hard real-time guarantee.

Platform reference: Blumenkamp, Shankar, Bettini, Bird, and Prorok, *The Cambridge RoboMaster: An Agile Multi-Robot Research Platform*, DARS 2024. https://arxiv.org/abs/2405.02198
